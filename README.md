# SCHOS — Sistema de Organización de Horarios Académicos

Proyecto académico de la materia Programación Orientada a Objetos.

## Objetivo
Desarrollar un sistema para organizar horarios académicos y gestionar
la información de las clases involucradas.

## Tecnologías
- Python 3
- Git y GitHub
- Visual Studio Code

## Estructura
- modelos/: clases del sistema.
- practicas/: ejercicios iniciales utilizados como referencia.

## Estado actual
El proyecto está en su etapa inicial de organización.
Las prácticas son ejemplos independientes; todavía no existe
una aplicación integrada.

## Trabajo en equipo
Cada integrante trabaja en una rama para su tarea, registra sus
avances mediante commits y abre un pull request para revisarlos
antes de incorporarlos a main.
